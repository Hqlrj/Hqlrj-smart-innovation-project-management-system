## 测试步骤

### 测试1：上传计划书（第1步）

**接口：** `POST /projects/upload-plan`

**前置条件：** 需要先登录获取JWT token

```bash
# 1. 先登录获取token
curl -X POST http://localhost:8080/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"your_username","password":"your_password"}'

# 假设返回的token是: eyJhbGciOiJIUzI1NiJ9...

# 2. 上传计划书
curl -X POST http://localhost:8080/projects/upload-plan \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "files=@c:/Users/Lenovo/Desktop/智能创新创业项目管理系统/code2/SpringBoot-project/uploads/project-plans/3447d645-6bc9-4b88-ac69-f5d72ee063a3.docx" \
  -F "projectId=1"
```

**预期结果：**
- ✅ 上传成功，返回计划书信息
- ✅ 数据库 `project_plan` 表中新增记录
- ✅ `file_hash` 字段有值（SHA-256指纹）
- ✅ 文件保存在 `uploads/project-plans/` 目录

**异常测试：**
- ❌ 上传非.docx文件应被拒绝
- ❌ 上传伪.docx文件（实为pdf）应被拒绝
- ❌ 上传超大文件（>100MB）应被拒绝

### 测试2：发起人工审核（第2步）

**接口：** `POST /projects/{id}/start-review`

**前置条件：**
- 项目已存在
- 项目状态为 `submitted`
- 已上传计划书

```bash
curl -X POST http://localhost:8080/projects/1/start-review \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"MANUAL"}'
```

**预期结果：**
```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "projectId": 1,
    "reviewMode": "MANUAL",
    "taskId": null,
    "taskStatus": null,
    "message": "已选择人工审核模式"
  }
}
```

**验证：**
- ✅ 数据库 `project` 表中 `review_mode` 字段为 `MANUAL`
- ✅ 接口在3秒内返回

## 常见问题排查

### 问题1：编译错误


### 问题2：数据库连接失败
**检查：**
- 确认MySQL服务已启动
- 确认 `application.properties` 中的数据库配置正确
- 确认数据库 `bsgl` 已创建

### 问题3：文件上传目录权限问题
**检查：**
- 确认 `uploads/project-plans/` 目录存在
- 确认目录有写入权限
- 确认工作目录正确（应为 `SpringBoot-project`）

### 问题4：SQL脚本执行失败
**解决方案：**
- 检查MySQL用户权限
- 检查表是否已存在（如果已存在，先删除或修改脚本）
- 使用 `DROP TABLE IF EXISTS` 避免冲突
