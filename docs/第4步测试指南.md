## 常见问题排查

### 问题1：POI依赖缺失
**错误信息：** `ClassNotFoundException: org.apache.poi.xwpf.usermodel.XWPFDocument`

**解决方案：**
- 检查 `pom.xml` 中是否有 poi-ooxml 依赖
- 执行 `mvn clean install` 重新下载依赖

### 问题2：文件路径错误
**错误信息：** `文件不存在: xxx`

**解决方案：**
- 确认文件路径使用正确的分隔符（Windows用 `\`，Linux用 `/`）
- 确认文件确实存在
- 使用绝对路径而不是相对路径

### 问题3：编码问题
**错误信息：** 解析出的文本乱码

**解决方案：**
- 确认文档编码为UTF-8
- 检查POI版本是否兼容

### 问题4：内存不足
**错误信息：** `OutOfMemoryError`

**解决方案：**
- 增加JVM堆内存：`-Xmx1024m`
- 分段处理大文档
