### 测试3：验证章节切分质量

**验收标准（根据文档）：**
- ✅ 标题召回率 ≥ 90%
- ✅ 「如第一章所述…」未被误判为标题
- ✅ 含目录页文档，目录未变成几十个空章
- ✅ 章节字数之和 ≈ 全文 95%+

**手动验证方法：**

#### 3.1 标题召回率验证
1. 用Word打开测试文档
2. 打开「视图」→「导航窗格」
3. 统计导航窗格中的标题数量
4. 对比数据库中的章节数量
5. 计算：召回率 = 数据库章节数 / Word标题数

#### 3.2 反误判验证
查询数据库中的章节标题，检查是否有以下情况：
- "如第一章所述"
- "参见第二章"
- "详见第三部分"

如果有，说明反误判规则需要调整。

#### 3.3 目录页验证
检查数据库中是否有大量短章节（charCount < 50），可能是目录页被误判。

#### 3.4 字数和验证
```sql
-- 计算数据库中章节字数总和
SELECT SUM(char_count) as total_section_chars 
FROM ai_review_section 
WHERE task_id = 1;

-- 对比文档解析结果中的totalChars
-- 应该 >= 95%
```

### 测试6：章节权重验证

```sql
-- 查看章节权重
SELECT sort_order, section_title, char_count, 
       (char_count * 1.0 / (SELECT SUM(char_count) FROM ai_review_section WHERE task_id = 1)) as weight
FROM ai_review_section 
WHERE task_id = 1
ORDER BY sort_order;
```

**验证点：**
- ✅ 权重之和 ≈ 1.0
- ✅ 字数多的章节权重高
- ✅ 权重 = 章节字数 / 总字数

## 常见问题排查

### 问题1：章节切分数量为0
**可能原因：**
- 文档没有明显标题结构
- 标题识别规则过于严格
- 数据清洗失败

**解决方案：**
- 检查文档是否真的有标题
- 调整 `SectionSplitUtil.isHeading()` 方法
- 检查日志看是否有异常

### 问题2：章节标题为空
**可能原因：**
- 标题段落文本为空
- 清洗时标题被误删

**解决方案：**
- 检查原始段落文本
- 调整清洗逻辑

### 问题3：目录页被误判为章节
**可能原因：**
- 目录页的正则匹配失败
- 引导点线特征未正确识别

**解决方案：**
- 增强 `TOC_PATTERN` 正则
- 调整反误判规则

### 问题4：章节层级判断错误
**可能原因：**
- 样式名称判断优先级不对
- 正则匹配优先级不对

**解决方案：**
- 调整 `determineSectionLevel()` 方法中的优先级
- 确保大纲级别优先级最高
