## 技术实现

### 1. 数据清洗实现

#### 全角/半角统一
```java
// 全角数字转半角
if (c >= '０' && c <= '９') {
    sb.append((char)(c - '０' + '0'));
}
// 全角字母转半角
else if (c >= 'Ａ' && c <= 'ｚ') {
    sb.append((char)(c - 'Ａ' + 'a'));
}
// 全角标点转半角
else if (c == '，') sb.append(',');
```

#### 敏感信息脱敏
```java
// 手机号脱敏：138****5678
masked = PHONE_PATTERN.matcher(masked).replaceAll("$1****$2");

// 邮箱脱敏：保留前3位和@后域名
masked = EMAIL_PATTERN.matcher(masked).replaceAll("$1***@$2");
```

#### 软换行合并
```java
// 如果上一行以结束标点结尾，则保留换行（段落分隔）
if (lastChar == '。' || lastChar == '！' || lastChar == '？') {
    sb.append("\n");
} else {
    // 否则认为是软换行，用空格连接
    sb.append(" ");
}
```

### 2. 章节切分实现

#### 标题识别（优先级）
1. **大纲级别**（outlineLvl 0-2）
2. **样式名称**（Heading 1/2/3、Title）
3. **正则匹配**（L1/L2/L3）

#### 正则表达式
```java
// 层级1：一、二、三、 或 第X章
Pattern LEVEL1_PATTERN_1 = Pattern.compile("^第[一二三四五六七八九十百零]+[章篇]");
Pattern LEVEL1_PATTERN_2 = Pattern.compile("^[一二三四五六七八九十]+[、.．]");
Pattern LEVEL1_PATTERN_3 = Pattern.compile("^[【\\[]\\s*[^】\\]]{2,20}\\s*[【\\]]$");

// 层级2：1.1、1.、1、
Pattern LEVEL2_PATTERN_1 = Pattern.compile("^\\d+\\.\\d+(\\.\\d+)?\\s*[、.．]?\\s*\\S");
Pattern LEVEL2_PATTERN_2 = Pattern.compile("^\\d+[、.．]\\s*\\S");

// 层级3：（一）、(1)
Pattern LEVEL3_PATTERN = Pattern.compile("^[（(][一二三四五六七八九十\\d]+[）)]");
```

#### 反误判规则
```java
// 长度超过30字
if (text.length() > 30) {
    return false;
}

// 以句号、分号、逗号结尾
if (text.endsWith("。") || text.endsWith("；") || text.endsWith("，")) {
    return false;
}

// 目录页特征（引导点线）
if (TOC_PATTERN.matcher(text).find()) {
    return false;
}

// 句内引用
if (text.startsWith("如") || text.startsWith("参见") || text.startsWith("详见")) {
    return false;
}
```

#### 章节权重计算
```java
// 章节权重 = 章节字数 / 总字数
double weight = (double) section.getCharCount() / totalChars;
section.setWeight(weight);
```

- 当前文档解析、数据清洗、章节切分都是同步执行
- 可能会阻塞接口响应（超过3秒）
- 后续需要改为异步执行
